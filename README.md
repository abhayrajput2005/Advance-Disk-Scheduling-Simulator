## 📖 Overview

The **Advanced Disk Scheduling Simulator** is an educational operating systems project that demonstrates how advanced disk scheduling algorithms process disk I/O requests.

The simulator allows users to input custom disk requests, visualize disk head movement, compare algorithm performance, and understand the impact of different scheduling strategies on seek time and efficiency.

---

## ✨ Features

- 🎯 Interactive Disk Scheduling Simulation
- 📊 Real-time Disk Head Animation
- 📈 Dynamic Seek Time Graphs
- ⚡ Algorithm Performance Comparison
- 📝 Custom Disk Request Input
- 🔄 Step-by-Step Execution
- 📉 Total Seek Time Calculation
- 🎨 Clean & Responsive User Interface

## 🧠 Supported Algorithms

### Traditional Algorithms
- FCFS (First Come First Serve)
- SSTF (Shortest Seek Time First)
- SCAN
- C-SCAN
- LOOK
- C-LOOK

### Advanced Algorithms
- N-Step SCAN
- FSCAN
- Interactive Scheduling

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Advanced-Disk-Scheduling-Simulator.git
```

### Navigate to Project

```bash
cd Advanced-Disk-Scheduling-Simulator
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```
